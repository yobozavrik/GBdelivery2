# GalaDelivery v2.0 🚀

Сучасний PWA-застосунок для автоматизації обліку закупівель, відвантажень та доставок польовими командами.

## 🌟 Ключові можливості
- **Офлайн-перший підхід**: Працюйте без інтернету, дані надійно зберігаються в **IndexedDB**.
- **Розумні звіти**: Генерація щоденних підсумків за допомогою AI (n8n + Gemini) з локальним резервним копіюванням.
- **Миттєве сканування**: Підтримка фото-чеків з автоматичним стисненням для економії трафіку.
- **Два режими**: Легке перемикання між "Тестовим" та "Робочим" середовищами.

## 🛠 Технологічний стек
- **Frontend**: Vanilla JavaScript (ES6+ Модулі), HTML5, CSS3 (Glassmorphism).
- **Storage**: IndexedDB (Primary), LocalStorage (State).
- **Service Worker**: Просунуте кешування та фонова синхронізація.
- **Backend**: Інтеграція з n8n Webhooks (`gbdelivery2`).

## 📁 Структура проекту
- `app.js` — Головна логіка та ініціалізація.
- `src/` — Модульна архітектура:
  - `config.js` — Глобальні налаштування та вебхуки.
  - `state.js` — Управління IndexedDB та станом.
  - `network.js` — Клієнт для зв'язку з n8n.
  - `ui.js` — Рендеринг, тости, анімації та тема.
  - `validation.js` — Захист від некоректного вводу.

## 🚀 Швидкий старт
1. Скопіюйте проект на локальний диск.
2. Використовуйте будь-який статичний сервер (наприклад, `npx serve .`).
3. Відкрийте додаток у браузері. Для роботи PWA рекомендується використовувати домен з HTTPS або localhost.
